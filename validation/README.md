# User validation corpus

Cumulative validation corpus for the SP16 Steel Verification Engine.

- Registered cases: **9** (`VAL-SP16-...-0001` through `0009`).
- Original attached files are preserved byte-for-byte when available.
- Chat-pasted reports are stored as explicit transcriptions and are not mislabeled as original source files.
- Every case preserves source metadata, expected values, production results, comparison status, source-side defects and package-remediation links.
- A scalar replay PASS does not promote a case to end-to-end GOLDEN unless the complete normative input/procedure chain is independently established.
- Current corpus revision: `0009`.
